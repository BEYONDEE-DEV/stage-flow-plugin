# Language Policy

Use the configured `language` for explanatory prose. Preserve the fixed English schema:

- config keys and controlled values
- Atom frontmatter keys
- required Markdown headings
- `atom_key`, `depends_on`, source locators, and RID tokens

Korean docs therefore use Korean prose under the fixed English headings. Keep source identifiers in their original spelling. Translate meaning, not identifiers, and do not add parallel bilingual prose unless the user requests it.
